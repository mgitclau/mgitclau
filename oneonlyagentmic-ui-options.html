OneOnlyAgentMic UI 方案

三種方案的差別在資訊架構：App 打開後，你先看到什麼。畫面內容都是範例。橫向滑動可看完整組畫面，也可用下方按鈕只比較同一種畫面。

比較
方案 A

時間河流

所有內容按時間排成一條河。錄音、逐字稿、心智圖和提醒都掛在當時的對話底下。

優點

  • 像聊天紀錄和相簿，不用學
  • 回想「那天說了什麼」最快
  • 處理進度就在每筆錄音上

缺點

  • 錄音多時，待確認事項會被沖走
  • 同一件事分散在不同日期
方案 B

待辦收件匣

Agent 的產出像郵件一樣進收件匣，逐張確認、歸檔或略過。錄音退到背景。

優點

  • 待確認事項最不容易漏
  • 每次打開都知道該做什麼
  • 一手就能處理完

缺點

  • 像多了一份工作，容易累積未讀
  • 想找舊對話要多一步
方案 C

錄音儀表

把手機當成專業錄音設備。深色介面，第一眼看電平、音源和連線，內容收在次層。

優點

  • 錄音狀態最可靠，出問題馬上知道
  • 深色省電（OLED），會議中不刺眼
  • 適合長時間錄音

缺點

  • 讀逐字稿時，資訊密度偏高
  • 對日常查看提醒的人太工具化

建議：以方案 A 為主，併入方案 B 的待確認區

每天最常做的事是回看對話，時間軸最自然。方案 A 的弱點是待確認事項被沖走，所以在時間軸最上方固定一張「待確認 3 件」，點開就是方案 B 的逐張確認流程。方案 C 的電平與音源資訊放在錄音中的全螢幕頁。
