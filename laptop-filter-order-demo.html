篩選抽屜方案 Demo

右邊是可以點的示意抽屜，台數與分布圖用資料庫上架中的 370 台真實資料即時計算。

先選一個情境（用戶在對話裡說了什麼）

在抽屜裡點了條件之後按這顆：你設的條件會排到最上面。抽屜開著的時候順序不動。

這個方案的 4 件事

  1. 預設照常用度排（電商式）：價格 → 品牌 → 尺寸 → 重量 → 顯卡 → CPU 品牌 → 記憶體 → 硬碟 → 遊戲效能 → 續航 → 更新率 → 面板 → 解析度 → 色域 → 噪音。
  2. 對話提到的條件自動排最上面，標「來自對話」；藏在深層的項目（例：Thunderbolt）也會直接出現。
  3. 6 項的操作方式修改：抽屜裡有黃色「改」字的就是，旁邊寫了原本的做法。
  4. 最多列 44 項：常用 16 項＋「更多條件」28 項；其餘約 200 個細項不列出來，用搜尋找。
